# Dataset yang Digunakan untuk Riset Kecil

1. **`loan_data_raw.csv`**: Dataset mentah dari Kaggle *Loan Prediction Problem Dataset* (614 baris, 13 kolom, masih memiliki nilai kosong dan format kategorikal teks).
2. **`loan_data_cleaned.csv`**: Dataset hasil *data preprocessing* (614 baris, 13 kolom numerik bersih tanpa *missing values*, siap digunakan untuk pemodelan).
