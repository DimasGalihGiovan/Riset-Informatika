# Source Code Eksperimen

* **`eksperimen_loan_prediction.ipynb`**: Notebook Google Colab berisi tahapan eksplorasi data, imputasi *missing values*, pengkodean fitur, pembagian data 80:20, penerapan *oversampling* SMOTE pada data latih, pelatihan model *Logistic Regression* dan *Random Forest*, serta visualisasi kurva *ROC-AUC* dan *Confusion Matrix*.
